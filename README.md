# 📊 Power BI — Relatório Financeiro com Foco em UX

Projeto desenvolvido como desafio prático da formação **Power BI Analyst da DIO**, com foco na atualização de um relatório financeiro e na melhoria da **experiência do usuário**.

## 🎯 Objetivo

Aprimorar um relatório financeiro existente, aplicando conceitos de **UX, storytelling e navegação** para tornar a análise dos dados mais clara, intuitiva e interativa.

## 🛠️ Tecnologias e Recursos

* Power BI
* Indicadores (Bookmarks)
* Botões de navegação
* Segmentação de dados
* Visuais interativos
* Formatação e estilização de relatórios

## 📌 Melhorias realizadas

* Reorganização dos visuais com foco em **posicionamento e proporção**;
* Aplicação de **contraste** para destacar informações relevantes;
* Utilização de **segmentações** para facilitar a exploração dos dados;
* Ajustes na estilização dos visuais e das páginas;
* Criação de diferentes perspectivas de análise;
* Implementação de **botões de navegação** entre as páginas;
* Configuração dos estados dos botões para melhorar a interação;
* Desenvolvimento de menus de navegação nas páginas;
* Aprimoramento do storytelling do relatório.

## 🎨 Experiência do Usuário

Durante a atualização do relatório, foram considerados princípios de **posicionamento, contraste, proporção áurea e segmentação dos dados**, buscando criar uma experiência mais intuitiva e facilitar a interpretação das informações.

Também foram utilizados **indicadores e botões** para criar uma navegação mais dinâmica entre as diferentes visões e páginas do relatório.

## 📚 Aprendizados

Este desafio permitiu aprofundar conhecimentos sobre:

* Construção de relatórios com foco em UX;
* Storytelling com dados;
* Organização e hierarquia visual;
* Interatividade no Power BI;
* Uso de indicadores e botões;
* Navegação entre páginas;
* Criação de diferentes perspectivas para análise dos dados.
